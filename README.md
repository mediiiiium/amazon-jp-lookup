# amazon-lookup

エージェント（Claude Code、Claude アプリ、そのほか Agent Skills 形式を読めるもの）が amazon.co.jp の商品を **調べる** ためのスキル。検索・商品詳細・現在価格を、取得時刻つきの JSON で返します。

- 読むだけ。購入・カート・注文履歴・アカウントのページには触れません
- サーバーも API キーも要りません。エージェントがすでに持っているブラウザでページを開き、同梱のスクリプトで項目を取り出します
- 自分で巡回するクローラーではありません。ユーザーが指定した検索と商品だけを、人間の閲覧ペースで読みます

## 中身

```
skills/amazon-lookup/
  SKILL.md            手順・守ること・出力の形
  extract_search.js   検索結果ページから上位10件を取り出す
  extract_product.js  商品ページから価格・在庫・評価・仕様を取り出す
```

## インストール（Claude Code）

```sh
git clone <this repo> ~/amazon-lookup
ln -s ~/amazon-lookup/skills/amazon-lookup ~/.claude/skills/amazon-lookup
```

ブラウザ操作には Claude in Chrome 拡張を使います。

## ログインしていないプロファイルを勧める理由

Claude in Chrome は普段使っている Chrome のクッキーをそのまま使います。Amazon にログインしたまま読むと、次のようになります。

- 自動で読んだ操作が、買い物に使っているアカウントに結びつく
- ページに氏名やお届け先が表示される（同梱のスクリプトはそれらを返しませんが、ページ自体には出ています）

調べるだけならログインは要りません。Amazon にログインしていない Chrome プロファイルを別に作り、そこに拡張機能を入れて使うのが安全です。出力の `session` で、どちらの状態で取得したかが分かります。ログアウト状態では、Prime 価格・配送・一部のクーポンの表示がログイン時と変わります。

## 壊れたとき

Amazon のページ構造は予告なく変わります。項目が `null` になり始めたら、スクリプトのセレクタを直してください。推測で値を埋めないのが方針なので、読めない項目は `null` と `notes` に出ます。
