# amazon-jp-lookup

エージェント（Claude Code など、Agent Skills 形式を読めるもの）が amazon.co.jp の商品を **調べる** ためのスキル。検索・商品詳細・現在価格を、取得時刻つきの JSON で返します。

- 読むだけ。購入・カート・注文履歴・アカウントのページには触れません
- **エージェントであることを名乗って読みます。** すべてのリクエストのユーザーエージェントに `Agent/amazon-jp-lookup` を入れます（理由は下の「Amazon のエージェント条件」）
- サーバーも API キーも、外部のライブラリも要りません。同梱の `lookup.py` は Python 3 の標準ライブラリだけで動きます
- 自分で巡回するクローラーではありません。ユーザーが指定した検索と商品だけを読み、リクエストの間を最低3秒あけます

## なぜ作ったか

エージェントに「Amazon でこれを調べて」と頼めるようにしたかったのですが、ちょうどいい手段がありませんでした（2026年11月時点）。

- **公式 API**：商品情報の API（Creators API）は、アソシエイトとして売上の実績がないと使えません。個人が買い物の下調べに使うものではありません
- **既存の MCP サーバー**：多くはサーバー側でページを取得して解析する方式です。そのため、Amazon のボット対策とのいたちごっこが中心になっています。amazon.co.jp への対応を明示したものも見つかりませんでした
- **第三者の API**：データは安定して取れますが、有料です

そこで、ボット対策をくぐり抜けるのではなく、エージェントだと名乗って公開ページを読む方式にしました。

## Amazon のエージェント条件

Amazon.co.jp 利用規約には「エージェント」の節があります。エージェントは、すべてのリクエストのユーザーエージェントに `Agent/[agent name]` を入れて名乗ること、人間の操作をまねてエージェントであることを隠さないこと、CAPTCHA を迂回しないこと、Amazon がやめるよう求めたら従うことが求められています。

このスキルはそれに合わせて、次のように動きます。

1. ユーザーエージェントは `Agent/amazon-jp-lookup (+https://github.com/mediiiiium/amazon-jp-lookup)` で固定
2. ブラウザのふりをしない。クッキーを使わないので、常にログインしていない状態で読む
3. CAPTCHA や自動アクセスの案内、HTTP 403 / 429 / 503 が返ったら、解かずに止める（再試行もしない）
4. robots.txt でこのエージェントが止められていたら読まない

初版はブラウザ（Claude in Chrome）で読む方式でしたが、ブラウザは人間と同じユーザーエージェントで開くため、この条件を満たせません。2026年11月に今の方式へ作り直しました。

なお、利用規約の一般の条項は、「製品リスト、解説、価格などの収集と利用」や「ロボットなどのデータ収集・抽出ツールの使用」を利用の許可に含めていません。このスキルは個人が買い物の下調べに使う範囲を想定していますが、規約上の扱いを保証するものではありません。使うかどうかは各自で判断してください。Amazon から利用をやめるよう求められた場合は、やめてください。

## 中身

```
skills/amazon-jp-lookup/
  SKILL.md    手順・守ること・出力の形
  lookup.py   取得と項目の取り出し（search / product / price）
```

## インストール（Claude Code）

```sh
git clone https://github.com/mediiiiium/amazon-jp-lookup.git ~/amazon-jp-lookup
ln -s ~/amazon-jp-lookup/skills/amazon-jp-lookup ~/.claude/skills/amazon-jp-lookup
```

単体でも動きます。

```sh
python3 ~/amazon-jp-lookup/skills/amazon-jp-lookup/lookup.py search "ミックスナッツ 無塩"
```

シェルで Python を実行できない環境（ブラウザだけを持つエージェントなど）では使えません。

## 壊れたとき

Amazon のページ構造は予告なく変わります。項目が `null` になり始めたら、`lookup.py` のセレクタを直してください。推測で値を埋めないのが方針なので、読めない項目は `null` と `notes` に出ます。

`status: "blocked"` が続く場合は、Amazon がこのエージェントを止めている可能性があります。くぐり抜ける修正はしないでください。
