# amazon-jp-lookup

エージェント（Claude Code、Claude アプリ、そのほか Agent Skills 形式を読めるもの）が amazon.co.jp の商品を **調べる** ためのスキル。検索・商品詳細・現在価格を、取得時刻つきの JSON で返します。

- 読むだけ。購入・カート・注文履歴・アカウントのページには触れません
- サーバーも API キーも要りません。エージェントがすでに持っているブラウザでページを開き、同梱のスクリプトで項目を取り出します
- 自分で巡回するクローラーではありません。ユーザーが指定した検索と商品だけを、人間の閲覧ペースで読みます
- **Amazon にログインしていないブラウザプロファイルで使ってください**（理由は下の「ログインしないプロファイルで使う」を参照）

## なぜ作ったか

エージェントに「Amazon でこれを調べて」と頼めるようにしたかったのですが、ちょうどいい手段がありませんでした（2026年11月時点）。

- **公式 API**：商品情報の API（Creators API）は、アソシエイトとして売上の実績がないと使えません。個人が買い物の下調べに使うものではありません
- **既存の MCP サーバー**：多くはサーバー側でページを取得して解析する方式です。そのため、Amazon のボット対策とのいたちごっこが中心になっています。amazon.co.jp への対応を明示したものも見つかりませんでした
- **第三者の API**：データは安定して取れますが、有料です

そこで、エージェントがすでに持っているブラウザを使う方式にしました。人が見るのと同じページを、人と同じペースで読みます。サーバーも API キーも要りません。ページの構造が変わったら、スクリプトのセレクタを直せば済みます。

## 中身

```
skills/amazon-jp-lookup/
  SKILL.md            手順・守ること・出力の形
  extract_search.js   検索結果ページから上位10件を取り出す
  extract_product.js  商品ページから価格・在庫・評価・仕様を取り出す
```

## インストール（Claude Code）

```sh
git clone https://github.com/mediiiiium/amazon-jp-lookup.git ~/amazon-jp-lookup
ln -s ~/amazon-jp-lookup/skills/amazon-jp-lookup ~/.claude/skills/amazon-jp-lookup
```

ブラウザ操作には Claude in Chrome 拡張を使います。

## ログインしないプロファイルで使う

Claude in Chrome は普段使っている Chrome のクッキーをそのまま使います。Amazon にログインしたまま読むと、次のことが起きます。

1. **閲覧履歴とおすすめが混ざる**：エージェントが調べた商品が、あなたの閲覧履歴とおすすめに入ります
2. **誤操作で買える状態になる**：スキルはクリックを禁じていますが、それは手順上の約束です。ログアウトしていれば、仕組みとして購入できません
3. **個人情報がエージェントに渡る**：ページに氏名やお届け先の郵便番号が表示されます。同梱のスクリプトはこれらを返しません。ただ、JavaScript を実行できない環境ではページの表示を読むので、一緒に読み込まれます
4. **アカウントへのリスク**：自動操作と判定された場合、影響を受けるのは購入履歴や Prime があるアカウントです

検索も商品ページもログインなしで見られます。Amazon にログインしていない Chrome プロファイルを別に作り、そこに拡張機能を入れて使ってください。

```sh
open -na "Google Chrome" --args --profile-directory="AmazonLookup"
```

このコマンドで新しいプロファイルが開きます（macOS の場合）。拡張機能の追加と Claude へのログインは手作業です。

出力の `session` で、どちらの状態で取得したかが分かります。ログアウト状態では、Prime 価格・配送日・一部のクーポンの表示がログイン時と変わります。

## 壊れたとき

Amazon のページ構造は予告なく変わります。項目が `null` になり始めたら、スクリプトのセレクタを直してください。推測で値を埋めないのが方針なので、読めない項目は `null` と `notes` に出ます。
